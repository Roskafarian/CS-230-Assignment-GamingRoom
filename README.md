# CS-230-Assignment-GamingRoom
This is a semi full stack development for the hypothetical company, 'The Gaming Room' and their game 'Draw it or Lose it'.

The client "The Gaming Room" wanted to port their Android-based game "Draw it or Lose it" to Desktop and iOS platforms using full-stack development techniques. As someone with imposter syndrome, I will always feel that my code and implementation thereof can be better than it currently is. However, I feel that most adequate was my implementation of security/authorization was particularly well done. The design document acted as a blueprint for what I would build in terms of what needs to be accomplished and achieved. The security implementation will likely be antiquated in the coming years (if not months) with the advent of Generative AI models that can immediately decrypt and decode secure standards of today. In working with this customer, I found it prudent to implement their design as, at the end of the day, they are the ones who requested the software. Their request of porting it to different platforms simplistically and frugally made me consider the implementation to using a browser-based application for desktop environments instead of trying to create standard thick clients for different operating systems. The strategy I used to create this document (and ultimately the app itself) was minimum viable product. What can be achieved with minimal cost and minimal invasiveness.
